# Autonomous Surface Vessel Navigation and Riverbed Perception

This project implements a ROS 2 and Gazebo simulation of a small autonomous surface vessel operating under time-varying current disturbance. The system includes waypoint-following control with feedforward current compensation, a simulated multibeam sonar configured after the Tritech MicronGemini 720s, riverbed point-cloud mapping from real Missouri River I-64 bathymetry data, and terrain-aided Monte Carlo localization using sonar observations. The control module publishes velocity commands for waypoint missions, while the perception pipeline reconstructs the riverbed map and evaluates it against ground-truth bathymetry using RMSE, error heatmaps, and trajectory visualizations; the localization module compares MCL output against Gazebo ground-truth odometry. The final experiments demonstrate robust waypoint tracking, a reconstructed riverbed map with 0.42 m RMSE, and sonar-based localization suitable as a fallback when visual-inertial odometry is not reliable.
